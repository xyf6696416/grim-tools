## 阶段 25（2026-09-21 上午）· 主轴普查：这条线「叠什么伤害最高」

**用户问**：狂战士+夜刃这条线，考虑星座/技能/装备，**叠什么属性伤害最高**。

**结果**（含减抗口径，同一 harness；现状基线 154,506）：

| 目标 | 合计 | 主桶 |
|---|---|---|
| **合计（无主轴）** | **178,003（+15.2%）** | 穿刺 122,000（68.5%）+ 流血 49,155（27.6%） |
| 流血 | 164,488（−7.6%） | 流血 101,898 |

**结论**：**穿刺为主 + 流血为辅**（两开花）—— ★ **单堆任何一种都掉合计**。

## 阶段 26（2026-09-21 中午）· 人形态「猛袭+雪崩」+ 伤害转化解法全普查

**用户方向**：「狼人攻击不能叠加其他伤害」⇒ 看 **猛袭 + 雪崩** 这条路 + 「冰冷转穿刺」思路 + **其他解法**。

**做了什么**：

1. **核实 WPS 触发判据**（`gd/rotation.py` §1672）：WPS 只在**默认攻击带武器伤害**时触发。
   狼人野性利爪 `weaponDamagePct` 70→150%、猛袭 100→170% ⇒ 模型判**触发**；鸦人寒冰之爪 = 0 ⇒ 不触发。

   （模型只看 `weaponDamagePct`）。若确认，狼人口径要按 **WPS 占比 18%** 折减。

2. **人形态加点必须手工**（新陷阱 **#64**）：`make_alloc` 默认贪心点了 3 条夜刃 WPS + 雪崩 + 血牙
   ⇒ **ΣW = 118 > 100 ⇒ 猛袭权重 0**（面板只剩 61,096，猛袭一次不出现）。

   修法：`make_alloc --set "…"`（只加指定项、**不贪心填充**）或直接写 alloc JSON。

3. **人形态全链实测 = 87,859**（含减抗，+26.9%，穿刺占 78.3%）
   ⇒ **只有狼人形态 178,003 的 49%**。根因不是加点，是**技能本体**：
   狼人爪击带**穿刺平伤**（`offensivePierceMin` 12→237+ 逐级）+ `werewolf2` 流血平伤/暴伤
   + `passive04` 独立乘区；而**猛袭只有 170% 武器伤害、平伤 = 0**。
   ⇒ **人形态这条路的上限就是狼人的一半，不建议作为主力路线。**

4. ★★ **伤害转化全库普查**（1970 件底材 / **55 种组合**）：
   - **→穿刺有 8 类来源**：**元素 100%（25 件）** ＞ 闪电 100%（13 件）＞ 活力 60% ＞
     **冰冷 50%（16 件）** ＞ 毒素 50% ＞ 混乱 45% ＞ 火焰 45% ＞ 以太 25%
   - ⇒ **「冰冷→穿刺」的正解是「元素→穿刺」**：上限更高 + 元素含火冰电三条通吃 + 可跨槽位叠加

   - **每槽位最高**：副手 45%（加林索尔的头颅）/ 武器 100%（雷霆喷射者、巫登沼泽闪电喷射器）/

     ⇒ **绿装前缀才是改伤害类型的主力，此前完全没被用起来**（现有方案只用了 2 个底材转化）
   - **护甲穿透**（`pierceRatio`）官方排在**所有转化之后**、只作用**未被转过**的物理 ⇒ 与装备转化**互补**

## 阶段 27 · 纯联网复核「减伤逻辑」（用户要求：**不读本地工作文件**，避免被既有模型误导）

**目的**：绕开自家实现，独立用公开资料（日文 wiki 实测 / Crate 论坛置顶口径 / 俄语社区大样本实测 /
官方 Game Guide / 官方补丁说明）核对两条链的口径。

**A. 敌方降抗（RR）三类 —— 顺序确认**

| 类 | 措辞 | 叠加 | 运算 |
|---|---|---|---|
| ① | `-n% XX Resistance` | **可叠加**（不同技能来源求和） | 加算 |
| ② | `n% Reduced target's Resistances` | 只取最高一条 | **乘算** |
| ③ | `n Reduced target's Resistances` | 只取最高一条 | 减算 |

- **生效顺序 ① → ② → ③**（多个独立来源一致：日文 wiki / 俄语 1.0.6.1 大样本实测 / Crate 论坛置顶 /
  RoT 中文站）。**英文 Fandom wiki 的旧修订版与大量中文转载写反了（说 ② 先算）** ⇒ 这就是误导源。
- **敌抗可成负、不锁 0**；① 把抗性压负后，② 改为 `×(1+②/100)` **继续加深负值**（`rot.grimda.cn` 表述为
  「对乙取绝对值」）。`R = (R₀ - Σ①) × (1 ∓ ②/100) - ③`。
- 措辞自识别：**带独立持续时间 = 标准 debuff**（②/③）；**技能行内无持续时间 = ①**。
- 由**武器打击触发**的普通 buff（含 ①/②）数值按**武器伤害 %** 折算，>100% 不放大。
- **同名技能来源不叠加**（两枚 Voidheart ≠ -20%，只是触发更频繁）；减全抗 vs 减单抗「不完美叠加」
  （同项取最高，其他项保留全抗效果）。**PvP 只按 1/5 生效**（②/③）。

**B. 我方减伤链（官方 Order of Defense，9 层顺序）**

fumble/dodge/投射偏移 → OA/DA 命中 → **盾** → 种族 % 减伤 → **抗性** → **护甲** → 种族点数减伤 →
**% 伤害吸收** → **点数伤害吸收**（最后结算，逐段扣）。
⇒ 盾在抗性**之前**；种族 % 减伤在抗性之前；点数吸收绝对最后。

**C. 护甲与吸收（数值）**

- 护甲**只挡物理**；**默认吸收率 70%**，`+20%` 加成 ⇒ `70%×1.2 = 84%`；**30% 永远穿透**；
  超出护甲值的部分**全额通过**。部位命中概率 头15/肩15/躯干26/臂12/腿20/脚12。
- ★ **实数伤害逐个独立过护甲**（多段小伤害对护甲极不利），不是先求和再减。
- **% 伤害吸收 = 乘算**（20% + 15% ⇒ 32%，不是 35%）；**点数吸收 = 加算**，且对 DoT 逐 0.1s 生效。
- ★★ **怪物护甲吸收率已变过两次**：v1.2.1.6 起**固定 70%**（此前终极难度 **77.5%**）→
  v1.3.0（Fangs of Asterkarn）**再降 20% ⇒ 56%**，且 Champion+ 怪物护甲 **-17%**。
  ⇒ 物理/直伤口径若仍按 70% 或 77.5% 建模，**物理桶被高估**。
- 减伤 debuff「`n% 标的目标伤害`」**不叠加取最高**；属性限定与全局**各取最高**（20% 全局 + 30% 物理
  ⇒ 物理减 30%、其余减 20%）；位置在**格挡/护甲减法之前**。种族减伤（% 类）**加算**。
- **OA/DA 削减**：`-X OA/DA` **可互相叠加**（仅技能来源）；`X Reduced target's OA/DA` **取最高**；
  两者之间可叠加。PTH 官方公式与阈值 70/90/105/120/130/135 → 1.0/1.1/1.2/1.3/1.4/1.5，PTH 下限 55。
